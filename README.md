# Job Application Tracker

A Trello-style board to track job applications: Wishlist, Applied, Interview, Offer, Rejected.
Built in 7 days as a full-stack practice project (building in public).

**Live demo:** _add after Day 7_

## Features
- Register / login (JWT)
- Create, edit, delete applications
- Drag and drop between stages
- Notes, follow-up dates, status history
- Search, stage filter, pagination
- Dashboard with counts and recent activity

## Tech stack
React (Vite), Tailwind CSS, React Router, Axios, Node.js, Express, MySQL (mysql2), JWT, bcrypt, Zod/Joi

## Documentation
See the `docs/` folder: PRD, ARCHITECTURE, API, DESIGN, BUILD_PLAN, BUILD_LOG, TEST_CHECKLIST, DEPLOY, USER_RESEARCH.

## Run locally
1. Clone the repo
2. `server/`: copy `.env.example` to `.env`, run `schema.sql` in MySQL, `npm install`, `npm run dev`
3. `client/`: copy `.env.example` to `.env`, `npm install`, `npm run dev`
