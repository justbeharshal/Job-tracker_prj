# Design

## Exactly 7 screens
1. Login  2. Register  3. Dashboard  4. Board  5. Applications list  6. Add/Edit application (modal)  7. Application detail

## Navigation
Left sidebar: Dashboard, Board, Applications only. User menu with Logout top right. "New Application" button on Board and Applications.

## Tokens
- Light theme only, desktop first, responsive
- Font: Inter
- Primary: indigo #4F46E5; neutrals slate; background #F8FAFC; white cards
- 12px radius, soft shadows, 8px grid
- Stage colors: Wishlist slate, Applied blue, Interview amber, Offer green, Rejected red

Put exported design images in `docs/design/`. Prompts to generate them are in `PROMPTS.md`.
